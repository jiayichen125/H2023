## 算法整理（含补充理由后的版本）

### 题目前提保证
- top-2峰值一定分属两个不同信号（两个信号峰峰值均为1V保证，三角波基频≈0.811V远大于其3次谐波≈0.090V）
- B的3次/5次谐波**不可能**污染A的3次谐波位置（否则 $f_B \leq f_A$，矛盾）
- 因此A的3次谐波位置的唯一可能污染源只有**B的基频**

---

### 完整流程

```
Step 1: 找top-2基频峰值 → A->bin=低频A, B->bin=高频B（已完成）
Step 2: 预取 A的3次(3fA)、5次(5fA) 位置幅值
（已定义对应index、未获取）

Step 3: 分支
  Case <1>: A的3次≈0 且 5次≈0  → 跳 Step 5
  Case <2>: A的3次 有幅值       → 跳 Step 4
  Case <3>: A的3次≈0 但 5次有幅值。说明A的五次和B基频或三次谐波重叠，无论哪种情况A都可以判定为正弦
            → A=正弦（三角波3次必强于5次，3次≈0说明A无谐波）
            → B类型待补充（查B的3次谐波 3×fB）

Step 4: A的3次有幅值
  Branch <2> 无重叠（3fA ≠ fB）:
    → 3次幅值来自A自身 → A=三角波 → B=正弦（题目约束）✓

  Branch <1> 有重叠（3fA = fB，即 fB=3fA）:
    → 改用A的5次谐波（5fA，无污染）判断A:
      - 5次/基频 ≈ 1/25 → A=三角波 → B=正弦 ✓
      - 5次≈0         → A=正弦   → B类型待补充（查B的3次谐波 9fA）

Step 5: A的3次和5次均≈0
  → A=正弦 ✓
  → 查B的3次谐波（3fB，无污染）:
      - 比值≈1/9 → B=三角波 ✓
      - 比值≈0   → B=正弦   ✓
```

### 重新评估

| 场景 | 路径 | 结果 |
|------|------|------|
| 正弦(A)+正弦(B)，普通比 | Case<1>→Step5 | ✓ |
| 正弦(A)+三角(B)，普通比 | Case<1>→Step5 | ✓ |
| 三角(A)+正弦(B)，任意比 | Case<2>→Step4 Branch<2> | ✓ |
| 三角(A)+正弦(B)，fB=3fA | Case<2>→Step4 Branch<1> 5次确认 | ✓ |
| 正弦(A)+正弦(B)，fB=5/3×fA | Case<1>→Step5（B正弦无谐波不污染5fA） | ✓ |
| 正弦(A)+任意(B)，fB=3fA | Case<2>→Step4 Branch<1>，A=正弦后 | **B类型缺判** |
| 正弦(A)+三角(B)，fB=5fA | Case<3> | **B类型缺判** |
| 正弦(A)+三角(B)，fB=5/3×fA | Case<3>（B的3次=5fA有幅值） | **B类型缺判** |
| 正弦(A)+正弦(B)，fB=5fA | Case<3>（fB基频=5fA有幅值） | **B类型缺判** |

**所有缺口的共同特征**：A已确定为正弦，但B的类型未判。修复方法统一：**查B的3次谐波位置（$3 \times f_B$），该位置在所有这些情况下均无污染（A是正弦，无谐波）**，直接做比值判断即可。
